About Bcrypt

Bcrypt is a password hashing function designed by Niels Provos and David Mazières, based on the Blowfish cipher. It is specifically designed for password hashing, incorporating a salt to protect against rainbow table attacks and adaptive cost to defend against future improvements in computing power.

Key Features:

  • Salt: Automatically generates and incorporates a random salt to protect against rainbow table attacks
  • Cost Factor: Adjustable work factor allows you to increase computational cost as hardware gets faster
  • Slow: Intentionally CPU-intensive to make brute-force attacks impractical
  • Future-Proof: Can be made slower over time as computing power increases

Hash Format:

A bcrypt hash string has the format: $2b$[cost]$[22 character salt][31 character hash]

  • $2b$ identifies the hash algorithm version
  • [cost] is the cost factor (e.g., 10)
  • [salt] is a 22-character salt
  • [hash] is the 31-character hash

Security Note:

This tool performs client-side hashing using JavaScript, which is suitable for educational purposes but not recommended for production systems. In a real application, password hashing should be done server-side to prevent exposure of unhashed passwords.
